# Caixa Eletrônico em Python

Projeto desenvolvido durante meus estudos de Python, após a conclusão dos módulos 1 e 2 do Curso em Vídeo.

## Funcionalidades

- Consultar saldo
- Realizar depósitos
- Realizar saques
- Validar opções do menu
- Validar valores de depósito e saque
- Encerrar o programa

## Conceitos praticados

- Variáveis
- Estruturas condicionais
- Laços de repetição
- Entrada e conversão de dados
- Validação de dados
- Operações matemáticas
- Formatação de valores

## Objetivo

O projeto foi desenvolvido para praticar lógica de programação e aplicar os conceitos aprendidos em Python.
